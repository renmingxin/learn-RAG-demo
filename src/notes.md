# RAG核心逻辑

## 解决什么问题
RAG的核心逻辑是解决用户的问题，而不是直接回答用户的问题。
RAG通过将用户的问题转换为向量表示，然后与数据库中的向量表示进行相似度计算，从而找到最相关的文档。
RAG通过将这些文档转换为文本表示，最后将文本表示转换为语音表示，从而实现RAG的核心逻辑。 

## 知识库的创建-离线索引流水线设计。
1. 文档加载【拓展：图片、视频、多模态】
2. 文档切片
3. 向量量化
4. 向量存储


## 开发流程
1. 加载文档
    -使用docloader加载文档
2. 文档切片
3. 向量量化【向量化的模型的作用就是将文档转换为多维向量】
    -使用openai的embedding模型将切片后的文档进行量化 
4. 向量存储
    -将量化后的向量存储到数据库中
